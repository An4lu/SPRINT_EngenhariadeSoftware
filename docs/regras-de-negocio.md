# Regras de Negócio

# Introdução

As regras de negócio foram definidas considerando o contexto industrial do Metaindústria e os requisitos operacionais de segurança preventiva.

O objetivo é garantir:

- conformidade operacional
- prevenção de acidentes
- rastreabilidade de eventos
- resposta rápida a riscos críticos

---

# Regras Operacionais

| Código | Regra |
|---|---|
| RN01 | Todo operador em área crítica deve utilizar EPIs obrigatórios |
| RN02 | A ausência de EPI deve gerar alerta imediato |
| RN03 | Posturas classificadas como críticas devem gerar evento de risco |
| RN04 | Todo evento operacional deve possuir registro temporal |
| RN05 | Eventos críticos devem atualizar dashboards em tempo real |
| RN06 | O sistema deve armazenar histórico de conformidade |
| RN07 | O sistema deve classificar níveis de risco |
| RN08 | Ocorrências reincidentes devem possuir rastreamento histórico |
| RN09 | O sistema deve consolidar indicadores operacionais |
| RN10 | Relatórios devem considerar setor, operador e período |
| RN11 | O sistema deve permitir análise de tendências operacionais |
| RN12 | Ocorrências críticas devem possuir prioridade operacional |

---

# Classificação de Risco

## Baixo Risco

Ocorrências com baixa probabilidade de acidente imediato.

Exemplo:

- ausência momentânea de luvas em área controlada

---

## Médio Risco

Ocorrências que podem gerar acidentes operacionais moderados.

Exemplo:

- postura inadequada recorrente
- ausência parcial de EPIs

---

## Alto Risco

Ocorrências com potencial crítico de acidente.

Exemplo:

- ausência de capacete em área pesada
- exposição em área crítica
- movimentação insegura próxima a máquinas

---

# Regras de Alertas

## Alertas Imediatos

Disparados automaticamente para:

- ausência crítica de EPIs
- movimentações inseguras
- riscos ergonômicos severos

---

## Alertas Preventivos

Disparados em situações de comportamento recorrente.

---

# Regras de Histórico

O sistema deve:

- registrar data e horário
- armazenar setor da ocorrência
- armazenar operador relacionado
- registrar nível de risco
- manter rastreabilidade histórica
