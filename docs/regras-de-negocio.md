# Regras de Negócio

| Código | Regra |
|---|---|
| RN01 | Todo operador em área crítica deve utilizar EPIs obrigatórios |
| RN02 | A ausência de EPI deve gerar alerta imediato |
| RN03 | Posturas classificadas como críticas devem gerar evento de risco |
| RN04 | Todo evento deve possuir registro temporal |
| RN05 | Eventos críticos devem atualizar o dashboard em tempo real |
| RN06 | O sistema deve armazenar histórico de conformidade |
| RN07 | Relatórios devem considerar período, setor e operador |
| RN08 | O sistema deve classificar níveis de risco |
| RN09 | Eventos recorrentes devem ser rastreados |
| RN10 | O sistema deve consolidar indicadores operacionais |
