# Levantamento de Requisitos

# Introdução

O levantamento de requisitos foi realizado considerando o contexto operacional do Metaindústria, priorizando monitoramento contínuo, prevenção de acidentes e rastreabilidade operacional.

A solução foi projetada como ferramenta operacional industrial e não como sistema administrativo ou de RH.

---

# Requisitos Funcionais

| Código | Requisito |
|---|---|
| RF01 | O sistema deve capturar fluxos contínuos de vídeo industrial |
| RF02 | O sistema deve detectar operadores em tempo real |
| RF03 | O sistema deve identificar ausência de EPIs |
| RF04 | O sistema deve detectar desvios posturais |
| RF05 | O sistema deve identificar movimentações críticas |
| RF06 | O sistema deve emitir alertas instantâneos |
| RF07 | O sistema deve classificar níveis de risco |
| RF08 | O sistema deve registrar eventos operacionais |
| RF09 | O sistema deve armazenar histórico de conformidade |
| RF10 | O sistema deve gerar dashboards operacionais |
| RF11 | O sistema deve consolidar indicadores industriais |
| RF12 | O sistema deve permitir exportação de relatórios |
| RF13 | O sistema deve registrar data e horário das ocorrências |
| RF14 | O sistema deve permitir rastreabilidade histórica |
| RF15 | O sistema deve monitorar múltiplas câmeras simultaneamente |

---

# Restrições do Sistema

- dependência da qualidade das câmeras industriais
- dependência de iluminação adequada
- possibilidade de oclusão parcial dos EPIs
- dependência da conectividade da rede
- limitação natural da inferência computacional
- possibilidade de falsos positivos e falsos negativos
