# Levantamento de Requisitos

# Requisitos Funcionais

| Código | Requisito |
|---|---|
| RF01 | O sistema deve detectar operadores em tempo real |
| RF02 | O sistema deve identificar ausência de EPIs |
| RF03 | O sistema deve detectar desvios posturais |
| RF04 | O sistema deve emitir alertas instantâneos |
| RF05 | O sistema deve registrar eventos de risco |
| RF06 | O sistema deve armazenar histórico de conformidade |
| RF07 | O sistema deve gerar relatórios analíticos |
| RF08 | O sistema deve exibir dashboards operacionais |
| RF09 | O sistema deve classificar níveis de risco |
| RF10 | O sistema deve permitir exportação de relatórios |
| RF11 | O sistema deve registrar data e hora das ocorrências |
| RF12 | O sistema deve monitorar múltiplas câmeras simultaneamente |

---

# Requisitos Não Funcionais

| Código | Requisito |
|---|---|
| RNF01 | O sistema deve operar em tempo real |
| RNF02 | O sistema deve possuir baixa latência |
| RNF03 | O sistema deve possuir alta disponibilidade |
| RNF04 | O sistema deve ser escalável |
| RNF05 | O sistema deve garantir integridade dos dados |
| RNF06 | O sistema deve possuir interface responsiva |
| RNF07 | O sistema deve garantir confiabilidade operacional |
| RNF08 | O sistema deve permitir modularidade |
| RNF09 | O sistema deve possuir segurança de autenticação |
| RNF10 | O sistema deve suportar crescimento industrial |

---

# Restrições do Sistema

- Dependência da qualidade das câmeras
- Dependência de iluminação adequada
- Possibilidade de oclusão visual dos EPIs
- Dependência da conectividade de rede
- Dependência da acurácia do modelo computacional
- Limitações naturais de inferência visual
